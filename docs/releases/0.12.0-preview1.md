# WindowsDeviceLink 0.12.0-preview1

This preview adds guarded native ARM64 support on full Windows 11 and completes a
focused operator-GUI polish pass.

## Native ARM64 Windows 11 support

- Native 64-bit ARM64 Windows PowerShell 5.1 is supported on full Windows 11 through
  the architecture-matching registered system DeviceLink runtime.
- The complete backend-assisted lifecycle was validated on physical ARM64 hardware:
  local identity retrieval, CSV export, tenant lookup, pre-association, association,
  refresh, cloud removal, local reset, full offboarding and reassignment.
- The support probe now reports the native process and operating-system architecture
  and allows only the registered-system-runtime route on ARM64.
- x64-emulated PowerShell on ARM64 is rejected explicitly because an emulated x64
  process cannot load the native ARM64 runtime correctly.
- ARM64 Windows PE and direct ARM64 DLL activation remain unsupported. The existing
  AMD64 Windows and AMD64 WinPE behavior is unchanged.

## Operator GUI

- The Device card now includes the system architecture without adding a fifth row.
- Assignment is presented separately from operational actions, leaving room for a
  future optional profile selector.
- Action groups, headings and the activity log were tightened to remain usable on
  768-pixel-high displays without an outer vertical scrollbar.
- Activity output wraps long lines instead of requiring horizontal scrolling.
- Copy and Clear are aligned consistently beside the Activity heading.
- The assignment separator is omitted when Target tenant is the final assignment row.

## Validation and documentation

- Added an architecture-policy regression test to CI.
- Recorded physical ARM64 Windows 11 lifecycle validation without retaining tenant,
  profile or device identifiers.
- Updated the README and installation guidance with the precise ARM64 support boundary.

This remains preview software. Use native ARM64 Windows PowerShell 5.1 for the ARM64
route and run `Test-WindowsDeviceLinkSupport` before performing DeviceLink operations.
