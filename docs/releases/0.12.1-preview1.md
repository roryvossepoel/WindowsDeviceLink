# WindowsDeviceLink 0.12.1-preview1

This preview prepares a consistent package for the next Windows 11 and AMD64 WinPE
validation round. It improves local recovery in the operator GUI and gives clearer
guidance when the process is not elevated.

## Local reset without tenant access

- In Direct mode, **Reset local** is available before sign-in or a cloud check for
  both `Interactive` and `DeviceCode`, including the default selected when running
  `Show-WindowsDeviceLink` without parameters.
- The supported runtime and known local firmware-state checks remain in place.
- Every local reset requires explicit GUI confirmation. The warning defaults to
  **No** and explains that no online check is performed and any cloud registration
  remains unchanged. Cancelling does not reset firmware.
- The result reports local reset only. It does not imply that the cloud registration
  is absent or that full offboarding has completed.
- This supports ownership-transfer recovery when an organization removed the cloud
  registration but left local DeviceLink state behind. No former-tenant credentials
  are needed for the local action.
- Backend mode retains its cloud-known-absent requirement for **Reset local**.
  **Remove both** retains its existing cloud verification and removal flow.

## Administrator guidance

- Starting the GUI without elevation now shows a clear **Run as administrator**
  instruction and stops before configuration retrieval, dashboard creation or
  firmware access.
- The underlying firmware privilege checks remain in place.

## Documentation and automated validation

- Added 20 mocked reset scenarios covering both Direct authentication methods,
  Windows PE, Backend gating, cloud states, local-state availability, cancellation,
  busy state and reset failure.
- Added checks for the default **No** confirmation, local-only command boundary,
  early elevation guard and process-token elevation detection.
- Updated GUI, offboarding and FAQ guidance, including private Backend launcher
  examples with placeholder keys and no mandatory `Read-Host` prompt.
- Expanded the README with CLI/GUI entry points, lifecycle guidance, multitenant
  mode selection, CI status and a preview-aware latest-version download badge.

## Validation still required

Hardware-independent CI is separate from physical-device validation. The new dialogs
and local-reset flow require a Windows/WinPE smoke test; the broader Direct, Backend
and OOBE scenarios remain in the [current validation checklist](../VALIDATION-CHECKLIST.md).
Record the exact source commit and whether each result used a candidate or the actual
Gallery package. Pending checklist items are not presented as passed.

Runtime support is unchanged: native 64-bit Windows PowerShell 5.1 on supported
Windows 11 AMD64/ARM64, and AMD64 WinPE with a compatible administrator-supplied
DeviceLink runtime. ARM64 WinPE remains unsupported. No Microsoft runtime DLL is
included. This package remains unsigned preview software.
